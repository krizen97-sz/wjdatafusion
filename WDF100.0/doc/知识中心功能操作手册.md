# 知识中心功能操作手册

## 1. 进入知识中心

拥有“知识中心”查看权限后，从左侧菜单进入知识中心。页面左侧是空间、搜索和目录，中间是当前知识正文，右侧是本文目录、关联知识和最近修改记录。

## 2. 阅读与搜索

1. 在左上角选择知识空间。
2. 在目录树中选择知识文章。
3. 使用“搜索本空间”按标题、摘要、正文或标签查找当前知识。
4. 正文底部可切换上一篇和下一篇；右侧“本文目录”可快速定位标题。

“当前知识”“已归档”“回收站”分别展示三个生命周期范围。只有拥有移除与恢复权限的用户可以查看回收站。

## 3. 创建和修改知识

拥有 `knowledge:page:write` 权限后：

1. 点击“新建知识”，填写标题、摘要、正文、目录、标签和修改说明。
2. 点击“保存新版本”后内容立即可见，不需要审核。
3. 阅读页点击“编辑知识”可继续修改；每次显式保存都会生成新的版本号。
4. 如果其他用户已经保存了更新，系统会停止本次覆盖并提示重新加载，当前编辑内容仍保留在页面中。

离开尚未保存的编辑页面时，系统会进行二次确认。

## 4. 关联现有文档

附件区与现有文档管理直接联动：

1. 在编辑页点击“选择现有文档”。
2. 从“我的文档”和“与我共享”中选择，单篇知识最多关联 20 份。
3. 保存知识后，附件区只记录文档 ID，不产生文件副本。
4. 阅读者点击附件时，系统继续使用文档管理的实时权限打开在线编辑、只读预览或下载。

没有文档管理权限时，可以修改知识正文并原样保留已有附件，但不能调整附件关系，也不会看到无权文档的标题等元数据。文档被归档、移入回收站、取消共享或共享到期后，附件状态会在下一次打开知识时自动更新。

## 5. 修改记录

点击“修改记录”可查看每个版本的修改人、时间、说明、变化字段、正文快照和关系快照。选择历史版本后点击“恢复为新版本”，系统会用该历史内容生成一个新的当前版本，原版本不会被覆盖或删除。

历史内容恢复不会自动改变知识当前的归档状态；回收站知识必须先执行“恢复知识”。

## 6. 归档与回收站

- 归档：适合保留但不再作为当前指引的知识，归档后仍可阅读和查看历史。
- 移入回收站：需要 `knowledge:page:remove` 权限。
- 恢复知识：从回收站恢复后重新进入“当前知识”。

系统不提供直接永久删除文章的页面操作，避免知识和修改记录不可恢复。只有空目录可以由空间管理员删除。
