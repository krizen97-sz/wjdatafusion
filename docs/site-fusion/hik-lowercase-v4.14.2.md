# v4.14.2 hik统一小写

按本次明确要求，设备账号的当前显示、保存和实际SSH登录统一使用小写hik，
覆盖v4.14.1的“大写显示、保留实际用户名”策略。

- 账号列表、编辑框、密码列、导入确认、登录策略和校验结果均显示hik。
- 后端通过SupportServerAccountNames统一固定账号，兼容旧记录的大小写形式。
- 服务器系统账号、账号表及硬件登录账号在API读取和保存时统一该固定账号名。
- 工作簿直接编辑与历史账号删除同样兼容旧大小写，避免界面可看但不能保存或删除。
- SSH校验在建立连接前再次规范用户名，实际认证使用hik。
- 不修改密码内容、root或其他用户名，不修改远端设备配置。
- 无数据库结构升级；不批量重写旧数据，只在读取和实际使用时兼容，用户保存时规范。
- 内部协议枚举和历史版本记录保留，不把旧版本描述改写成新规则。

继续复用现有账号面板、工作簿及Element Plus组件，没有新UI组件、样式或依赖。
参考现有EquipmentAccountsPanel和EquipmentLoginCheck，不改变布局与权限。

验收包含历史大小写读取、保存及密码保持原样；隔离SSH服务只接受hik，
测试以旧大小写输入调用校验器仍能通过，从协议握手层证明实际用户名正确。
未用业务设备密码发起真实服务器登录。本地同步和重启记录保存在交付目录，
不发布250。
