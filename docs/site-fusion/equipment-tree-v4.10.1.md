# v4.10.1 设备关系树与顶部切换

基线：已验证的本地main a8c7bd9（v4.10.0），包含最新origin/main 9f08809。

## 调整

- 删除设备清单底部Sheet页签，替换为左侧Element Plus原生关系树。
- 层级为现场、主平台、子平台；另外保留主平台直属设备及公共/未归属平台入口。
- 每个节点右侧展示设备数量，以来源类型和ID去重。共享设备可以出现在多个子平台中，但父级不重复累计。
- 当前平台/全现场开关、目录搜索都在关系树内，清单和机房图均可使用。
- 树的数量表示当前范围总量，不因右侧关键字或设备类型筛选改变；表格计数表示筛选后的数量。
- 切换范围回到范围根节点；切换清单/机房视图保留所选树节点。
- 改变目录节点清空批量选择、分页和明文缓存；所选导出继续按设备唯一标识限定范围。
- 复用已有平台树和拓扑查询，同时刷新目录与设备数据，不新增接口。
- 顶部标题、视图切换和刷新/关闭保持独立固定布局；模式专属命令在下一行。
- 窄屏将同一目录收进原生Drawer，顶部切换入口不随模式变化移动。

## 复用与边界

| 需求 | 既有能力 | 参考 |
| --- | --- | --- |
| 关系树与搜索 | el-tree、el-input、el-scrollbar | system/user、IPAM目录 |
| 范围和视图 | el-segmented、motion-control-label、项目图标 | 现有设备工作区 |

没有新依赖、UI框架、全局主题覆盖或UI例外。沿用UIX-004拓扑及UIX-011设备网格边界。
不修改后端或数据库，不需要升级SQL，也不需要重启8080。
