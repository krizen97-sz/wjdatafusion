# v4.10.0 现场画布与设备工作簿

基线：origin/main / 9f08809。开发分支：codex/site-fusion-inventory-workbook-v4-10-0。

## 功能与边界

- 关系画布详情默认关闭，使用 Element Plus Drawer；不再固定占用300/330px。
- 初始化、刷新和切换现场不会自动展开详情；“查看详情”提供明确入口。
- 搜索与工具栏按可用宽度换行，不以提高z-index掩盖布局问题。
- 平台、页面、组织、联系人共用 SiteEntityForm；画布入口与独立管理页保持一致。
- 移除这些编辑窗口的装饰标题、重复预览以及137条不再使用的样式规则。
- 详情区的编辑也进入同一标准表单，保留组织、角色、网络环境和密码留空不修改等规则。
- 页面右键新增“复制密码并打开页面”，保留“跳转页面”；仅接受HTTP/HTTPS且地址不能含登录凭据。
- 设备默认进入工作簿，可切换机房图；复用现有设备录入、编辑、位置、链路、凭据与模板确认流程。
- Sheet按子平台ID区分，显示主平台路径；保留全部设备及公共/未归属子平台，避免漏掉设备。
- 同一设备在多个Sheet出现时仍是同一资产，不复制数据库记录。
- 支持查询、原生分页、全选当前Sheet、选择导出、删除所选及统一明文显示。
- 数据仍来自统一topology投影，补充已有SSH端口及操作系统字段，不恢复已撤除的重复设备列表接口。
- 当前分页发生在完整现场投影上，不宣称改成了数据库分页；后续超大现场可单独扩展服务端分页。
- 明文按当前页最多100台批量读取；Sheet、翻页、关闭、刷新时使旧请求失效并清除缓存。
- 网格只读，修改使用业务表单；不包含单元格任意粘贴写库或文档协同编辑。
- 新增SSH默认55555；已有端口、历史位置和平台关系不批量修改。

## 安全与接口

- 新增 POST /support/equipment/credentials/plain，复用support:credential:viewPlain和datafusion规则。
- 所有设备引用先校验来源、ID、现场，整批验证后才解密；重复引用去重，不跨现场返回密码。
- 支持服务器多条凭据、旧系统登录密码和硬件登录密码；不把多个账号压成一条资产记录。
- 明文响应设置Cache-Control: no-store，不进入通用响应日志。
- 页面明文接口关闭响应日志，页面新增修改关闭请求体日志；修复历史明文日志风险。
- 密码不进入URL、本地存储、普通清单接口或隐藏状态的网格数据；未修改数据库加密策略。
- 复制使用浏览器Clipboard API和原有execCommand方式兼容内网HTTP；失败不宣称复制成功。
- 新窗口被拦截时保留已复制结果并提示继续打开，不重复请求密码。
- 设备导出增加类型加ID的选择范围过滤；保留逐设备类型导出权限。
