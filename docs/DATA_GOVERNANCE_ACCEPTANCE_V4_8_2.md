## 产品改进

主线统一为“选任务 → 选择和配置节点 → 保存 / 预览 → 查看结果 → 运行 / 定时计划”。任务名称、版本、保存状态、执行服务状态集中到页头，保存/预览/运行成组；新建和导入归入任务库，输入文件/数据库连接及任务设置/调度/历史按用途分组。

- 工具名称与能力标签同行，任务名称和节点数/版本分层。无节点选择时收起属性区，任务库/属性区可独立收起；窄屏通过面板切换保留操作入口。
- 节点表单使用滚动内容区和固定操作区；说明可折叠，复杂字段表可以展开。原生参数、未知XML、既有权限与执行行为保留。
- 结果在同一组件内全宽展开，返回时保留选项。作业默认指标，失败默认日志；运行编号和长异常进入详情。样本条数、引擎累计计数和未返回值分别说明。
- 所有定义变更入口共用执行保护：运行中、结束整理中、状态待核查均只读。旧历史不能替换活动运行而意外解锁。调度的启用/更新/立即运行受保护，暂停与恢复核查仍保留。
- 连接草稿绑定任务并纳入退出提醒；保存和导出前必须应用或取消。输入删除、历史、停止和字段检查的迟到响应有归属检查。
- URL 只保存当前有权访问的任务 ID，刷新可恢复；空图保留原 FlowDiagram 的真实拖放目标。深色选中背景改用已有主题表面变量，避免浅色背景配浅色文字。
