# 平台按钮反馈 v4.11.0

## 范围

沿用 Element Plus、现有图标和 Precision Rail。共享 CSS 覆盖当前 Vue 3 平台的
原生按钮，不改变权限、点击回调、接口或字段；不涉及 Vue 2、后端、数据库。
现场清单前三个业务列为行政区、现场编码、现场名称，选择框与其余列保留。

## 参考与适配

- [LottieFiles 按钮目录](https://lottiefiles.com/free-animations/button)：查看按钮、方向、
  加载和成功反馈分类；单项详情遇到安全验证，没有下载或引入外部动画文件。
- [LottieFiles UI 状态反馈说明](https://lottiefiles.com/blog/design-inspiration/struggling-with-engagement-heres-how-ui-animation-can-fix-it)：
  借鉴悬停、进行中、完成的可辨状态，不照搬营销动画或无限弹跳。

| 操作 | 复用方式 | 约束 |
| --- | --- | --- |
| 查询、新增、修改、普通按钮 | 共享颜色过渡、图标微移1px、按压1px | 不缩放文字，不悬停移动整个按钮 |
| 上传、导出、下载模板 | `data-motion-direction="up/down"` | 图标最多2px，仅显式适配入口 |
| 保存、执行、上传确认 | `motion-execute-action` + `v-motion-ripple` | 有界反馈，非危险操作，保留原有真实loading |
| 进行中 | 原生loading与平台标识，按钮内部细轨道 | 只由真实loading驱动，不伪造百分比 |
| 原位成功 | 现有 `is-motion-success` 状态 + 图标进入 | 只复用已由接口成功驱动的状态，不新增延时假成功 |
| 行内修改、删除、取消、文本链接 | 原生颜色、焦点和禁用反馈 | 不做Ripple或位置跳动 |
| Tabs、分段开关、画布自绘控件 | 保留现有原生轨道和模块交互 | 不套普通按钮动效，不改布局切换状态 |

普通过渡使用共享120/160/220ms变量。Reduced Motion保留颜色、焦点、加载标识，
移除按钮及图标位移、轨道循环和Ripple。无新依赖，无动画CDN、计时伪成功或全局DOM扫描。

## 搜索布局

画布搜索不再使用带负边距的 Input append 按钮。原生输入框和文字按钮并列：
输入可收缩，按钮不收缩，组合最大宽度不超过容器；窄屏切为纵向工具栏时，
清除原横排的300/900px flex基准，防止高度被错误撑开。
普通与全屏画布复用同一搜索控件，Enter与点击仍使用原来的查询方法。

## 验证

- `npm run verify:frontend`：254项测试通过，生产构建通过。
- `npm run ui:guard`：0错误、0警告；沿用7项既有UIX-004例外，未增加例外。
- 构建兼容扫描：161个JavaScript文件通过Chrome 64+语法检查，非真实Chrome 64实机验收。
- 真实已登录现场：列序、搜索点击及Enter、普通/全屏按钮命中区域。
- 只读模拟数据、实际组件：390/768/1024/1440px布局，浅/深色，上传方向、
  loading及原生键盘防重复、成功态、减少动态效果；没有改动原有点击反馈指令。
- 代表性的保存按钮在idle/loading两态宽度同为108px；没有更改Element Plus原生尺寸机制。
- 没有逐一执行所有模块的增删改业务；公共样式以组件状态矩阵验收，未写入业务测试数据。
- 设计检测器仅提示现场画布已有网格背景：它服务拓扑定位，保留现有UIX-004例外。

## 回退

本版本仅修改前端；回退本次前端提交即可，不需要数据库恢复或后端替换。
