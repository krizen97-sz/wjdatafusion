## 分批整改

1. 普通 CRUD、工具页和系统页：按钮语义、可访问名称、footer、提交 loading。
2. support 列表页：统一查询、表格、状态、Dialog 和主题变量。
3. 自动巡检与现场融合复杂页：只做显示层、可访问性、变量和已验证的组件替换。
4. 文档、知识、IPAM、版本中心：主题、空态、响应式和专业交互边界。
5. 全量 Guard、Impeccable detector、全部现有测试、生产构建与浏览器验收。

完成条件：所有 Guard 发现均已修复、确认是误报并修正规则，或有精确业务例外；不得遗留“未复核”项。
