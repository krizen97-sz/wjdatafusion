# 计划统计项目大屏 v4.4.0 / v4.4.1

## 功能边界

新增 `/autoInspection/cockpit?view=metrics` 计划指标视图，原运行总览通过 `view=overview` 保留。六类指标图来自真实的自动计划执行记录，不查询外部设备、不触发巡检，不写入数据库。

| 图表 | 数据来源与口径 |
| --- | --- |
| 统计项目数值趋势 | 所选步骤与目标的实际采样值、已记录的上次值，使用真实采样时间 |
| 实测与上次对比 | 所选项目最新采样记录中的实际值、上次值，使用同一单位 |
| 项目变化趋势 | 后端原始change_value，不在前端跨日推算变化；首次基线保留为空 |
| 区间极值统计 | 当前已加载数值样本的最小值、最大值和BigDecimal平均值 |
| 项目判定分布 | 所选项目全部已加载样本的正常、关注、异常、未执行状态，失败样本不因数值为空而消失 |
| 计划执行耗时 | 当前计划执行记录的duration_ms，一次执行只计一次，不按目标数量重复累加 |

## 查询接口

`GET /support/autoInspection/dashboard/metrics`

- 权限继续使用 `support:autoInspection:query`。
- `planId` 可选，首次选择最近有执行记录的现有计划；无效或已删除的计划明确报错。
- `days` 默认7，服务端允许1至30天，前端提供今天、近7天、近30天。
- 仅统计 `source_type=AUTO` 的计划执行记录；不把无计划的手动测试混入计划采样。
- 目标采样与执行记录分别最多读取最近5000条，多读1条用于识别截断；截断状态会显示在页面。
- 只读取计划、执行、步骤结果、目标结果四张已有表，不需要升级SQL。
- 返回计划目录、统计项目、采样点、区间统计和执行耗时，不返回密码、step_params、result_detail或error_message等可能携带敏感内容的字段。

## 数值安全

- BigDecimal以字符串传递，Tooltip和最新值保留原精度，避免大于JavaScript安全整数范围时被改写。
- 图表坐标使用有限浮点数绘制；完整精度始终以原始字符串和源记录为准。
- 同一目标的不同单位或不同统计窗口分别成组，不相加、不做隐式单位换算。
- 历史百分号转义形式`%%`仅在显示分组中规范为`%`，不回写数据库。
- 失败样本缺少单位时，仅在同一目标具有唯一已知单位时归入该单位；存在多种单位时保留未标注单位组。
- 缺失值不补0；有效的0值保留。首次建立基线时，上次值和变化量不作为可比数据展示。
