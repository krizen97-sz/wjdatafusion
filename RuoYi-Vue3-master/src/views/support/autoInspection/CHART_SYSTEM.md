# 自动化巡检本地图表系统

本模块保留 Vue 3、Element Plus 和 ECharts 5.6.0，不引入外部图表模板、字体、CDN 或运行时依赖。图表系统吸收“先识别数据契约、再选择图型；一张图表达一个结论”的方法，并按运维工作台语境重新实现。

## 数据契约

| 业务问题 | 数据形状 | 本地实现 | 主要结论 |
| --- | --- | --- | --- |
| 哪天运行、哪天异常 | 日期序列 + 总量 + 异常量 | 柱线组合图 | 异常峰值日期 |
| 今日结果如何构成 | 正常/异常/未检测 | 横向堆叠条 | 各结果直接计数 |
| 哪个工具最不稳定 | 工具 + 正常率 | 最差优先横向条 | 低于 90% 关注线的工具 |
| 异常集中在哪里 | 步骤 + 异常次数 | 异常 TopN | 首要处理步骤 |
| 当月哪天运行 | 日期 + 次数 + 异常 | 双序列日历热力 | 运行强度与异常日 |

## 视觉与交互规则

1. 标题说明图表回答的问题，右侧短句直接给出当前结论。
2. 正常、异常、关注、未检测使用固定语义色；图内同时提供数值、文字或排序，不只依赖颜色。
3. 异常排名和工具健康使用横向条，保留业务名称和直接数值，不使用难比较的饼图。
4. 趋势图的总量使用柱，异常使用折线和峰值标注，避免两个相近折线互相遮挡。
5. 工具健康度按正常率升序，最差项优先出现，并固定显示 90% 关注线。
6. 空数据由 option 构建器返回统一空态，不在页面组件里重复拼装。
7. 动画只用于数据更新，持续时间控制在 220-260ms；页面加载不做编排式动画。

## 本地能力

`inspectionChartSystem.js` 提供：

- `INSPECTION_CHART_TOKENS`：平台化颜色、文字和网格令牌。
- `buildInspectionInsight()`：把统计值转换为值守结论。
- `buildWeekTrendOption()`：周趋势和异常峰值。
- `buildResultCompositionOption()`：结果构成。
- `buildToolHealthOption()`：工具健康度和关注线。
- `buildAbnormalTopOption()`：异常 TopN。
- `buildCalendarHeatOption()`：月度日历热力。

新增巡检图表时先在本文件登记数据契约，再新增纯函数构建器和 Node 测试。页面只负责传入业务数据、初始化 ECharts 和处理 resize，不在 Vue 组件中重复维护颜色与 option 细节。

## 边界

- 不复制 Lieflat Charts 模板代码，不受其 HTML 结构约束。
- 不使用 Chart.js、Google Fonts、jsDelivr 或其他联网资源。
- 不把报告型编辑视觉直接搬进后台工作台。
- 后续周报/月报若需要图表图片，优先复用这些 option，通过本地浏览器渲染后嵌入文档。
