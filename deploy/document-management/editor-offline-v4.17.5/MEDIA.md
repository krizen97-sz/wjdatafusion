# RYNEW v4.17.5 离线升级介质

请先用和介质一同交付的 `.sha256` 文件核对外层归档，解包后在本目录执行 `sha256sum -c SHA256SUMS`。

- **已有正常运行的文档编辑服务。** 解开 `RYNEW-v4.17.5-offline-upgrade.tar.gz`，进入同名目录，按 `README.md` 准备现场参数、预检、升级、验收和回滚。升级前核对用户正在编辑的文档并完成保存。
- **首次安装编辑服务。** 同时解开 `RYNEW-Docs-9.4.0-linux-amd64-offline.tar`，先按主包的 `ENGINE.md` 安装本地引擎、生成私有配置并检查健康，再走平台升级流程。

主包内为 Java 17 后端 JAR、Vue 3 生产静态文件、Nginx 配置和 Python 3.8+ 运维脚本。引擎附件面向 Linux x86_64，使用已有 Docker Engine，包含可直接导入的编辑器与网关镜像、配套 Compose 工具和本地中文字体。平台沿用现场已有的数据库、Redis、存储路径及密钥。

本次文档优化针对 v4.17.2 及以上完整数据库基线，无新增 SQL。v4.8.4 起的旧现场数据库升级顺序见主包 `db/README.md`。数据库脚本由现场 DBA 按实际基线选择执行。
