## A. 基础设施

| 编号 | 场景 | 预期 |
|---|---|---|
| A01 | 固定镜像启动 | 容器状态为 `healthy`，镜像 ID 与部署记录一致 |
| A02 | API 脚本 | `/web-apps/apps/api/documents/api.js` 返回 200 |
| A03 | 回调链路 | DocumentServer 访问 `onlyoffice-gateway:8083` 返回 200，网关再转发到宿主机 8080 |
| A04 | 端口隔离 | 80、443、5554、8080、8081、9000 的原服务保持不变；DocumentServer 不发布宿主机端口，仅网关绑定 8082 |
| A05 | 运行时断网 | 断开互联网后，健康检查、API 脚本及业务回调仍正常 |
| A06 | 重启恢复 | `docker restart` 后恢复 healthy，RestartCount 无异常增长 |

## B. 文档与目录

| 编号 | 场景 | 预期 |
|---|---|---|
| B01 | 新建目录 | 目录刷新后仍存在，父子层级正确 |
| B02 | 新建 DOCX | 能进入在线编辑器，初始文件可正常保存 |
| B03 | 新建 XLSX | 能进入在线编辑器，公式与单元格修改可保存 |
| B04 | 可视化归档 | 拖放/操作菜单归档成功，可撤销并恢复原目录 |
| B05 | 实时保存 | 编辑状态从同步中恢复到已保存；每次内容变化只新增修改人/时间记录，新版本不保存独立历史文件或内容操作日志 |
| B06 | 最终保存 | 最后一位用户退出后当前文件保持最新，重新打开内容一致；数据库提交后被替换的旧当前文件自动清理 |
| B07 | 修改记录轻量化 | 页面仅显示版本号、修改人和时间，无文件大小、保存来源、历史下载或恢复入口 |
| B08 | 文件事务一致性 | 保存提交后删旧文件；保存回滚时保留旧当前文件并删除本次新文件 |

## C. 权限与协同

| 编号 | 场景 | 预期 |
|---|---|---|
| C01 | OWNER 授权 EDIT | 被授权用户可修改，同屏能看到双方变化 |
| C02 | OWNER 授权 VIEW | 被授权用户只能查看，编辑控件不可用 |
| C03 | 未授权直链 | 直接访问编辑路由和文件接口均被拒绝 |
| C04 | 权限撤销 | 新会话立即失效；存量会话按策略关闭后不可再保存 |
| C05 | 同文档双编辑 | 两个浏览器并发编辑无覆盖，用户列表和光标状态正常 |

## D. 安全与恢复

| 编号 | 场景 | 预期 |
|---|---|---|
| D01 | 错误编辑器 JWT | DocumentServer 拒绝加载或保存 |
| D02 | 过期文件令牌 | 平台文件接口拒绝访问 |
| D03 | 伪造回调 | 平台返回错误，不写文档、不新增版本 |
| D04 | 非白名单下载主机 | 平台拒绝拉取回调文件 |
| D05 | 成对备份恢复 | MySQL 元数据和文档存储恢复到同一时间点，文件可打开 |

验收记录必须区分：容器健康、接口连通、平台内部联调、真实多人浏览器协同。只有 D05 和完整 B/C 项通过后，才能标记为现场业务验收完成。
